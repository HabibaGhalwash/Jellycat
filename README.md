# Jellycat – Dynamic E-Commerce Frontend

A dynamic e-commerce website designed for Jellycat, a brand known for its playful stuffed animals and plush toys. The project focuses on creating a colorful, engaging, and user-friendly online shopping experience with product collections, product pages, shopping cart functionality, and multiple supporting pages.

## 📌 Project Overview

Jellycat is a frontend web development project created to simulate an interactive online store for plush toys.

The website combines a playful visual identity with an organized e-commerce structure, allowing users to browse products, explore themed collections, view product details, interact with the shopping cart, and navigate through different sections of the website.

The design uses soft colors, playful imagery, and themed product collections to create a warm and enjoyable shopping experience.
